# Features (Mobile / Flutter)

Estructura modular por funcionalidad (*Feature-Based*) compuesta por pantallas y widgets modulares (*Component-Based*), según lo definido en `docs/architecture/README.md`.

Cada funcionalidad dentro de este directorio encapsula sus propias pantallas, widgets, modelos y servicios:

```text
features/
└── [feature]/
    ├── screens/
    ├── widgets/
    ├── services/
    └── models/
```
