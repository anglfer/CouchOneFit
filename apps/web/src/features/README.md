# Features

Estructura modular por funcionalidad (_Feature-Based_), siguiendo la arquitectura definida en `docs/architecture/README.md`.

Cada funcionalidad dentro de este directorio encapsula sus componentes, vistas, hooks y servicios locales:

```text
features/
└── [feature]/
    ├── components/
    ├── pages/
    ├── hooks/
    ├── services/
    └── types/
```
