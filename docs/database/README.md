# Base de datos

Cada integrante creará las tablas que necesite para su funcionalidad mediante migraciones, explicando para qué sirven y cómo se relacionan con las existentes. Todos ejecutarán y probarán las migraciones en local y revisarán que los cambios sean compatibles entre sí. El responsable de integración centralizará y subirá las migraciones, las ejecutará y probará antes de aplicarlas en producción. Después, todo el equipo actualizará su código y base local a la misma versión.
