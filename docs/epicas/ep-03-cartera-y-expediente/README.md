# EP-03 — Cartera y expediente

Esta épica conserva un único expediente por cliente dentro de la cartera de su profesional. La primera historia implementada es [HU-015 — Crear el cliente y su expediente inicial](hu-015/README.md). No incluye evaluaciones, mediciones históricas, cálculo de grasa, nutrición, prescripciones ni los alcances de HU-016 a HU-020.
